# Итоговый проект МИФИ

**Разработка и автоматизация пайплайна для скоринговой модели предсказания дефолта (PD-модель)**

Модель оценивает риск дефолта по кредитной карте в следующем месяце. На открытом наборе UCI из 30 000 клиентов реализован путь от проверки входных данных до обслуживания прогнозов через API и контроля дрейфа.

| Компонент | Что открыть |
| --- | --- |
| Подготовка и анализ данных | [src/data.py](src/data.py), [ноутбук EDA](notebooks/01_eda.ipynb) |
| Признаки и валидация | [src/features.py](src/features.py), [src/validation.py](src/validation.py), [тесты данных](tests/test_data.py) |
| Обучение и сравнение моделей | [src/train.py](src/train.py), [результаты](docs/RESULTS.md), [ROC-кривая](reports/roc.png) |
| Воспроизводимость и автоматические проверки | [dvc.yaml](dvc.yaml), [GitHub Actions](.github/workflows/ci.yml), [тесты](tests/) |
| Сервис прогнозирования и мониторинг | [src/api.py](src/api.py), [Dockerfile](Dockerfile), [src/monitor.py](src/monitor.py) |

Лучшая модель — градиентный бустинг. На отложенной выборке из 6000 клиентов ROC-AUC составил **0,7797**, precision — **0,6592**, recall — **0,3527**, F1 — **0,4595**. При пороге 0,5 модель обнаруживает около 35% случаев дефолта. Пять конфигураций сравнивались по ROC-AUC на кросс-валидации обучающей выборки.

## Перед сдачей

1. Распакуйте ZIP и откройте [START_HERE.md](START_HERE.md). Данные, модель, отчёты и база MLflow входят в архив. После установки зависимостей API можно запустить с готовой моделью.
2. Подготовьте демонстрацию по [docs/DEMO.md](docs/DEMO.md). Для проверки Docker запустите Docker Desktop, соберите образ по инструкции и отправьте пробный запрос.
3. Выполните `git log --oneline` в корне проекта. История Git уже внутри архива. Создайте пустой репозиторий на GitHub и отправьте существующую ветку `main` по разделу «DVC и GitHub» в [README.md](README.md).
4. Дождитесь результата во вкладке Actions и проверьте, что преподаватель сможет открыть репозиторий. Приложите его ссылку в форму задания. ZIP приложите, если форма предусматривает загрузку архива.

В [отчёте о проверках](reports/verification.md) зафиксированы полное повторное обучение, пять запусков MLflow, 17 тестов и мониторинг на 300 HTTP-запросах. Удалённый GitHub Actions не запускался. После запуска Docker Desktop пользователь успешно собрал образ и получил тот же прогноз внутри контейнера.
