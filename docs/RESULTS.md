Градиентный бустинг глубины 2 выиграл по CV ROC-AUC; 100 деревьев оказались лучше 60 внутри GridSearchCV. Разница с логистической регрессией около 0,012 ROC-AUC. Это одно разбиение и три фолда, поэтому статистическую значимость превосходства не утверждаем.

При пороге 0,5 модель находит около 35% дефолтов, а около 66% положительных прогнозов верны. Для задачи банка цена пропущенного дефолта может быть высокой: такой порог нельзя автоматически считать подходящим для бизнеса. Следующее улучшение — выбор порога на out-of-fold (вне фолда обучения) прогнозах train с учетом стоимости ошибок, проверка калибровки и новая независимая оценка. Test текущего проекта не используется для подбора порога.

В MLflow сохранены пять окончательных успешных запусков из experiments.json. Есть и записи предварительных запусков: несовместимость сериализации была исправлена явным перечислением собственных доверенных типов и деревьев, созданных скриптом обучения. Ошибки не удалены из журнала. Перезагрузка модели MLflow проверяется сравнением с joblib-моделью API.

PSI на имитации 300 новых клиентов ниже 0,2. Это ожидаемо для случайно разделенного исторического набора и не доказывает отсутствие будущего дрейфа.
