# Credit Default MLOps — итоговый проект МИФИ / SkillFactory

Учебная система предсказания дефолта клиента в следующем месяце. Основной источник требований — загруженный PDF «1/2 Итоговый проект (PJ)», страницы 1–4. Папка проекта самостоятельная; синхронизированные материалы не изменены.

## Быстрый запуск

Требуется Python 3.12. Выполняйте команды из корня `credit-default-mlops`.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
# Локальный служебный кеш, совместимый с ограниченной средой.
export DVC_SITE_CACHE_DIR="$PWD/.dvc/site-cache"
export MPLCONFIGDIR="$PWD/.mplconfig"
pip install -r requirements.txt
# Загрузка оригинала из UCI (требует интернет).
python -m src.data download
# Исходные данные уже отслеживаются DVC в приложенной версии.
# При новой загрузке обновите их контрольную сумму:
dvc add data/raw
# Проверки, подготовка, анализ и пять экспериментов.
dvc repro
pytest -q
black --check src tests scripts
ruff check src tests scripts
```

`dvc repro` при неизмененных входах использует кеш. Для повторного обучения: `dvc repro --force train`. Для первого запуска в новом репозитории без `.dvc`: `git init`, `dvc init`, `dvc add data/raw`, затем `dvc repro`. В приложенной версии инициализация уже выполнена.

## Данные и решения

Источник: [UCI Default of Credit Card Clients](https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients), Yeh (2009), DOI 10.24432/C55S3H, лицензия CC BY 4.0. Kaggle содержит зеркало того же набора. Оригинал: 30 000 клиентов, 23 признака, история платежей за апрель–сентябрь 2005 года. Цель `default` — 0/1. Паспорт загрузки и SHA-256 архива: `data/raw/source.json`.

ID используется для проверки уникальности, но не входит в модель. EDUCATION 0/5/6 объединяем с 4 («другое»), MARRIAGE 0 с 3. Отрицательные BILL_AMT допустимы: запрещать их как аномалию нельзя. PAY -2 и 0 сохраняем как отдельные наблюдаемые коды, не придумывая им документированное значение. Остальные неизвестные коды приводят к ошибке проверки.

Разделение 80/20 стратифицированное, seed=42. EDA по train. Все медианы, масштабирование и кодирование обучаются внутри Pipeline и CV, что предотвращает data leakage (утечку данных). Пять экспериментов: три варианта LogisticRegression и два GradientBoosting; для бустинга перебираются 60/100 деревьев. Победитель определяется по среднему CV ROC-AUC. Test используется один раз после выбора. Порог 0.5 фиксирован заранее. Отдельно оцениваются precision (точность положительных прогнозов), recall (полнота), F1 (их гармоническое среднее). Вероятности не калибровались; банковским PD-скорингом промышленного качества эта учебная модель не является.

Great Expectations строго запрещает null во входном датасете. Imputer остается частью модели как требуемый этап и защита при последующем изменении политики. API требует все поля, конечные числа и допустимые коды. Демографические признаки включены для соответствия учебному набору; перед реальным использованием необходима оценка справедливости и калибровки.

## MLflow

```bash
mlflow ui --backend-store-uri sqlite:///mlflow.db --port 5000
```

Откройте http://localhost:5000. В эксперименте `credit-default` сравните пять запусков по `cv_roc_auc`. У победителя имеются `test_*`, график ROC и сравнение запусков. Каждый запуск содержит сохраненный pipeline и signature (схему входа и выхода). Номера запусков доступны в `reports/experiments.json`. Модели и база MLflow локальные. При переносе проекта на другой путь адреса артефактов в базе могут указывать на прежнюю папку; заново запустите обучение для нового журнала. Повторный `dvc repro --force train` создаст новые запуски.

## API и Docker

```bash
uvicorn src.api:app --host 127.0.0.1 --port 8000
# В другом терминале, с активной .venv:
python -m scripts.api_smoke
python -m src.monitor
```

Swagger (интерактивная документация): http://localhost:8000/docs. Пример тела запроса: `examples/client.json`. Ответ: `default_prediction`, `default_probability`. Модель загружается при старте; если ее нет, сервис не запускается. API принимает очищенные EDUCATION/MARRIAGE.

```bash
docker build -t credit-default:local .
docker run --rm -p 8000:8000 credit-default:local
python -m scripts.api_smoke
```

Контейнеру нужны уже созданные `models/pipeline.joblib` и зависимости. Docker daemon должен работать. Образ включает зависимости обучения, чтобы сохранить возможность их использования; исходные данные не включаются в образ.

## Мониторинг

Скрипт отправляет первые 300 клиентов test в работающий API и сравнивает распределения AGE, LIMIT_BAL, PAY_0 и вероятности с train. Границы интервалов определяются только по train; крайние новые значения учитываются. `reports/drift.json` содержит PSI — Population Stability Index (индекс стабильности распределения). Учебный alert при PSI ≥ 0.2; это эвристика, не доказательство ухудшения модели. Здесь имитация одного пакета, не постоянный сбор продукционных запросов. Метрики качества на новых клиентах требуют известных ответов default.

## DVC и GitHub

`data/raw.dvc` отслеживает исходники; `dvc.lock` фиксирует версии выходов. Локальный кеш `.dvc/cache` содержит данные и модель. Перед переносом на другой компьютер настройте удаленное хранилище:

```bash
dvc remote add -d storage /absolute/path/to/shared-storage
dvc push
git add .
git commit -m "Configure shared DVC storage"
```

Путь хранилища выбираете вы; внешнее хранилище автоматически не создается. При клонировании используйте `dvc pull`; если хранилища нет, `python -m src.data download`, `dvc add data/raw`, `dvc repro`. GitHub-репозиторий пока не опубликован. Для публикации создайте пустой репозиторий, добавьте его через `git remote add origin <URL>` и выполните `git push -u origin main`. После push CI запустится на GitHub; наличие workflow не означает, что удаленный запуск уже выполнен.

## Краткий словарь

| Термин | По-русски и назначение |
|---|---|
| Imputer | Заполнитель пропусков: заменяет их медианой или самым частым значением |
| Scaler | Масштабирование: приводит числовые признаки к сопоставимому масштабу |
| One-hot encoding | Кодирование категории отдельными столбцами 0/1 |
| Cross-validation / CV | Кросс-валидация: несколько разделений train для оценки и выбора модели |
| Stratification | Стратификация: сохранение соотношения классов при разделении |
| ROC-AUC | Площадь под ROC-кривой: качество ранжирования по вероятности дефолта |
| Grid search | Перебор заданной сетки параметров; C управляет регуляризацией, max_depth глубиной деревьев, n_estimators числом деревьев |
| Tracking | Учет параметров, метрик и результатов экспериментов |
| Artifact | Артефакт: сохраненный результат, например модель или график |
| DVC | Data Version Control — контроль версий данных и результатов этапов |
| CI | Continuous Integration — автоматические проверки при изменении кода |
| Endpoint | Адрес операции API, например /predict |
| Drift | Дрейф: изменение распределения новых данных относительно эталона |

Интеграция GX следует [официальному примеру для pandas DataFrame](https://docs.greatexpectations.io/docs/core/connect_to_data/dataframes/); в проекте зафиксирована и проверена версия 1.23.2.
