# Кредитный скоринг и MLOps

Итоговый проект МИФИ / Skillfactory по прогнозированию дефолта по кредитной карте в следующем месяце. Проект объединяет подготовку данных, обучение модели, автоматические тесты, запуск API в Docker и проверку дрейфа.

## Данные и модель

В наборе **Default of Credit Card Clients** 30 000 клиентов из Тайваня. На вход подаются кредитный лимит, демографические данные, суммы счетов и история платежей за шесть месяцев. Цель `default` принимает значение `1`, если в следующем месяце зафиксирован дефолт, и `0` в остальных случаях. [Источник и лицензия CC BY 4.0](https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients)

Great Expectations проверяет структуру таблицы, пропуски, типы и диапазоны значений. Из истории платежей рассчитываются дополнительные признаки, например число месяцев с просрочкой. ID клиента исключён из признаков модели.

Данные разделены на 24 000 строк для обучения и 6 000 для теста с сохранением долей классов. В scikit-learn предобработка и модель объединены в Pipeline. GridSearchCV подбирает параметры на обучающей выборке. Из пяти экспериментов по ROC-AUC кросс-валидации выбран градиентный бустинг с 100 деревьями глубины 2.

| Метрика на тесте | Значение |
| --- | ---: |
| ROC-AUC | 0,7797 |
| Precision | 0,6592 |
| Recall | 0,3527 |
| F1 | 0,4595 |

При пороге 0,5 модель обнаруживает около 35% фактических дефолтов. Вероятности не калибровались. Результаты относятся к историческому учебному набору. [Сравнение экспериментов](docs/RESULTS.md)

## Запуск

Из корня проекта с Python 3.12 выполните:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest -q
```

**После клонирования с GitHub** загрузите данные и воспроизведите подготовку, анализ и обучение:

```bash
python -m src.data download
dvc repro
```

DVC описывает этапы в [dvc.yaml](dvc.yaml). Версии исходных данных и результатов зафиксированы в `data/raw.dvc` и `dvc.lock`. Для восстановления из GitHub используются загрузка UCI и обучение. **Если вы распаковали полный ZIP**, данные и модель уже внутри. Следуйте [инструкции для архива](START_HERE.md), в том числе обновите пути артефактов MLflow командой `python -m scripts.relocate_mlflow`.

## API и Docker

Запуск на Mac:

```bash
python -m uvicorn src.api:app --host 127.0.0.1 --port 8000
```

Для запуска в Docker остановите локальный API и выполните `./scripts/run_docker.sh`. Скрипт собирает образ с готовой моделью и запускает контейнер на порту 8000.

В другом окне Терминала из папки проекта отправьте запрос:

```bash
.venv/bin/python -m scripts.api_smoke
```

Этот скрипт отправляет [пример данных клиента](examples/client.json) на `POST /predict`. На Mac прошли 17 тестов, а API напрямую и в Docker вернул один и тот же результат для примера — класс `1` и оценку риска около `0.6046`. Формат запроса можно посмотреть в [Swagger](http://127.0.0.1:8000/docs), пока сервис запущен.

## Эксперименты и мониторинг

MLflow сохраняет параметры, метрики и обученные модели. В запуске победителя также сохранена ROC-кривая. После обучения или переноса артефактов из архива откройте журнал командой `mlflow ui --backend-store-uri sqlite:///mlflow.db --port 5000`.

При запущенном API команда `python -m src.monitor` отправляет 300 строк тестовой выборки и сравнивает признаки и прогнозы с обучающей выборкой по PSI. Результат записывается в `reports/drift.json`. В демонстрационном прогоне ни один показатель не достиг порога 0,2.
